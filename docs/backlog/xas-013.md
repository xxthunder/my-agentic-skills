# [XAS-013] CI check that generated artifacts match canonical sources

**Status**: Open
**Priority**: Medium
**Epic**: XAS-004
**Component**: .github/workflows/

**Summary**:
As a reviewer, I want CI to fail when committed generated artifacts are stale relative to canonical sources so that the repo never ships out-of-sync content.

**Description**:
CI runs the generator and diffs the output against what's committed. If they differ, the build fails with a message pointing the author to rerun the generator locally.

**Acceptance Criteria**:
- [ ] CI workflow runs the generator on every PR
- [ ] CI fails on any diff between regenerated and committed artifacts
- [ ] Failure message explains how to regenerate locally
- [ ] Workflow completes in under 1 minute for typical changes
