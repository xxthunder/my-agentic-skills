# [XAS-009] Build generator that emits Claude Code plugin artifacts

**Status**: Open
**Priority**: High
**Epic**: XAS-003
**Component**: scripts/, build/

**Summary**:
As a maintainer, I want a script that reads canonical skill sources and produces valid Claude Code plugin output so that the existing installation flow keeps working after the architecture change.

**Description**:
Build a generator (language TBD — likely Node or Python) that consumes canonical sources and produces the `.claude-plugin/` + `skills/` layout Claude Code expects. Output should be deterministic and suitable for check-in, so consumers don't need the build step.

**Acceptance Criteria**:
- [ ] Generator runs locally with a single command
- [ ] Output installs as a working Claude Code plugin
- [ ] Generator is deterministic (no timestamps, stable ordering)
- [ ] Decision captured: output checked in vs. generated at install-time
- [ ] All existing skills generate correctly
