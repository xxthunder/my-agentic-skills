# [XAS-004] Marketplace tooling and CI

**Status**: Open
**Priority**: Medium
**Component**: .github/workflows/, scripts/, hooks/

**Summary**:
As a maintainer, I want automated validation and version management so that releases are consistent and generated artifacts stay in sync with canonical sources.

**Description**:
With a canonical source + generator model (XAS-003), we need tooling to enforce invariants: canonical sources are valid, versions across manifests stay in sync, and generated artifacts are never out of date in the repo.

**Substories**:
- XAS-004a — Pre-commit validation of canonical source format
- XAS-004b — Auto-sync version between plugin.json and marketplace.json
- XAS-004c — CI check that generated artifacts match canonical sources

**Acceptance Criteria**:
- [ ] Pre-commit hook fails on malformed canonical sources
- [ ] Version sync between plugin.json and marketplace.json is automated
- [ ] CI fails if committed generated artifacts are stale
