# [XAS-015] Launch `xxthunder-paperless-skills` plugin

**Status**: Open
**Priority**: High
**Component**: plugins/xxthunder-paperless-skills/, .claude-plugin/marketplace.json

**Summary**:
As a paperless-office builder, I want a dedicated plugin bundling scanning, merging, and filing skills so that I can digitize and sort household paperwork (family, house, car, etc.) with minimal friction.

**Description**:
Second plugin in the marketplace, dedicated to digitizing and managing physical paperwork. Seed with three skills: `simplex-merge` (already authored as a user-global skill, migrated here), `naps2-scan` (new — end-to-end scan pipeline), and `auto-file` (new — sort digitized documents into a configured folder structure).

**Scope Decisions**:
- **Plugin name**: `xxthunder-paperless-skills`.
- **Initial skills (3)**: `simplex-merge`, `naps2-scan`, `auto-file`.
- **Simplex-merge migration**: move, not copy — the global `~/.claude/skills/simplex-merge/` is deleted once the plugin install is verified. No parallel copies.
- **NAPS2 skill scope**: end-to-end pipeline — scan via NAPS2.Console.exe, OCR (Tesseract), chain into `simplex-merge` when input is two simplex halves, propose a content-derived filename.
- **Auto-file skill**: sorts into a given root folder with a user-configurable subfolder structure; classification is content-driven (based on OCR text / metadata).
- **Target OS**: Windows (NAPS2 is Windows-native).
