# [XAS-014] Phase 2 — Restructure to multi-plugin marketplace layout

**Status**: Open
**Priority**: High
**Epic**: XAS-002
**Component**: repo structure, CLAUDE.md

**Summary**:
As a marketplace maintainer, I want each plugin to live in its own subdirectory under `plugins/` so that additional plugins can be added without colliding with the existing one and so that the layout visibly reflects the marketplace framing.

**Description**:
Phase 2 of the rename epic. Today the repo is structured as a single plugin at the root (Layout 0). Move to Layout 1:

```
.claude-plugin/marketplace.json              # marketplace registry (root)
plugins/xxthunder-dev-skills/
  .claude-plugin/plugin.json                 # plugin manifest (moved)
  skills/<skill-name>/SKILL.md               # skills (moved)
docs/backlog/
```

`marketplace.json.plugins[0].source` changes from `"./"` to `"./plugins/xxthunder-dev-skills/"`.

**Scope Decisions**:
- Layout 1 chosen (per XAS-002 Scope Decisions): skill sources stay in native Claude Code format, no build step.
- Restructure now even though only one plugin exists — a second plugin is planned immediately after.
- CLAUDE.md paths need updating to reflect the new location.

**Acceptance Criteria**:
- [ ] `skills/` moved to `plugins/xxthunder-dev-skills/skills/`
- [ ] `.claude-plugin/plugin.json` moved to `plugins/xxthunder-dev-skills/.claude-plugin/plugin.json`
- [ ] `.claude-plugin/marketplace.json` remains at repo root
- [ ] `marketplace.json.plugins[0].source` updated to `"./plugins/xxthunder-dev-skills/"`
- [ ] CLAUDE.md paths updated to reflect new structure
- [ ] Install via `claude plugin marketplace add <repo>` + `claude plugin install xxthunder-dev-skills` works end-to-end
