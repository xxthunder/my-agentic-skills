# [XAS-010] Document how to add a new agent target

**Status**: Open
**Priority**: Low
**Epic**: XAS-003
**Component**: docs/

**Summary**:
As a future contributor, I want a clear guide on how to add a new agent target (e.g., Copilot) so that the marketplace can be extended without reverse-engineering the existing generator.

**Description**:
Write a guide explaining the generator architecture, how target emitters plug in, what fields each target consumes from canonical sources, and how to test a new target end-to-end.

**Acceptance Criteria**:
- [ ] Doc lives in `docs/`
- [ ] Covers generator architecture, target interface, and testing
- [ ] Includes a worked example (stub target or a real second target)
