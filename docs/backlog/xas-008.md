# [XAS-008] Define canonical skill source format

**Status**: Open
**Priority**: High
**Epic**: XAS-003
**Component**: skills/, docs/

**Summary**:
As a skill author, I want a single canonical format for skill sources so that one authored skill can be emitted to multiple agent targets without duplication.

**Description**:
Design a canonical format — likely YAML frontmatter + markdown body, close enough to Claude Code's existing SKILL.md to minimize migration but agent-agnostic in field naming. The format must capture: name, description, trigger conditions, body content, references, and any target-specific overrides.

**Acceptance Criteria**:
- [ ] Format spec documented in `docs/`
- [ ] Existing skills migrated to canonical format (or format is a superset and existing files already conform)
- [ ] Format distinguishes agent-agnostic fields from target-specific overrides
- [ ] Spec reviewed against Claude Code SKILL.md to confirm lossless emission
