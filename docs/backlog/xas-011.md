# [XAS-011] Pre-commit validation of canonical source format

**Status**: Open
**Priority**: Medium
**Epic**: XAS-004
**Component**: hooks/, scripts/

**Summary**:
As a skill author, I want malformed canonical sources caught before commit so that the generator doesn't fail mid-build or emit broken artifacts.

**Description**:
Add a pre-commit hook (or equivalent) that validates canonical source files against the format spec: required fields present, YAML parses, markdown body non-empty, no unknown fields.

**Acceptance Criteria**:
- [ ] Hook validates all canonical sources on commit
- [ ] Hook fails with an actionable error on malformed input
- [ ] Hook is installable via a single command (or runs via a standard tool like pre-commit)
