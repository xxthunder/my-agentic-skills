# [XAS-016] Scaffold `xxthunder-paperless-skills` plugin and register in marketplace

**Status**: Open
**Priority**: High
**Epic**: XAS-015
**Component**: plugins/xxthunder-paperless-skills/, .claude-plugin/marketplace.json

**Summary**:
As a maintainer, I want the plugin directory structure and manifest in place with a marketplace entry so that subsequent skills can be added to it and the plugin is installable via Claude Code.

**Description**:
Establish the minimal scaffolding for the new plugin:
- `plugins/xxthunder-paperless-skills/.claude-plugin/plugin.json` with name, description, version, repository, license
- `plugins/xxthunder-paperless-skills/skills/` directory (may be empty until XAS-017 adds the first skill)
- `.claude-plugin/marketplace.json` updated with a second entry under `plugins[]` pointing at `./plugins/xxthunder-paperless-skills/`

**Scope Decisions**:
- Starting version: `0.1.0` (pre-1.0 while skills are still being seeded).
- No repo-wide version coupling between plugins — each plugin versions independently.
- Marketplace registry version (`marketplace.json` itself has no version field today) remains unchanged.

**Acceptance Criteria**:
- [ ] `plugins/xxthunder-paperless-skills/.claude-plugin/plugin.json` created (valid JSON, correct schema)
- [ ] Plugin version starts at `0.1.0`
- [ ] `plugins/xxthunder-paperless-skills/skills/` exists
- [ ] `.claude-plugin/marketplace.json` has a second `plugins[]` entry
- [ ] `claude plugin install xxthunder-paperless-skills` succeeds against a local checkout (even with zero skills)
- [ ] CLAUDE.md updated if the multi-plugin note needs clarification (e.g., independent versioning)
