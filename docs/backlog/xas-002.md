# [XAS-002] Rename repo and restructure as agentic-skills marketplace

**Status**: Open
**Priority**: High
**Component**: repo-wide

**Summary**:
As a maintainer, I want the repo renamed to `xxthunder-agentic-skills` and repositioned as an agent-agnostic skill marketplace so that it can host skills targeting multiple agents beyond Claude Code and host multiple plugins over time.

**Description**:
The repo is currently named `xxthunder-dev-skills` and framed as a Claude Code plugin. The new positioning: an "agentic skill marketplace" — the repo is the marketplace, and the current dev skills become one plugin within it. This epic covers the rename, marketplace reframing, and folder restructure.

**Scope Decisions**:
- **Naming split**:
  - Repo → `xxthunder-agentic-skills`
  - Marketplace registry (`marketplace.json.name`) → `xxthunder-agentic-skills`
  - Plugin (`plugin.json.name`) → stays `xxthunder-dev-skills` (one plugin among future ones)
- **Folder layout — Layout 1**: skill sources remain in native Claude Code format. Each plugin lives under `plugins/<plugin-name>/`. Marketplace registry stays at repo root. No build step. Canonical-format decision deferred to XAS-003.
- **Restructure now, not later**: folder move happens now even though only one plugin exists — moving once is cheaper than moving twice; a second plugin is already planned.
- **Order of operations**:
  - Phase 1 (compatibility) — rename GitHub repo and update URL references only. Relies on GitHub's repo redirect, so nothing breaks.
  - Phase 2 (marketplace reframing) — rename marketplace registry, restructure folders, rewrite README. Lands together as one atomic change.

**Phases and child stories**:
- **Phase 1** — XAS-005 (GitHub rename + URL references)
- **Phase 2** — XAS-006 (manifest renames), XAS-007 (README rewrite), XAS-014 (folder restructure)

**Acceptance Criteria**:
- [ ] GitHub repo renamed to `xxthunder-agentic-skills`
- [ ] Marketplace registry renamed to `xxthunder-agentic-skills`
- [ ] Plugin name unchanged (`xxthunder-dev-skills`)
- [ ] Folder layout: `plugins/xxthunder-dev-skills/` contains plugin manifest + skills
- [ ] README describes the marketplace purpose
- [ ] All Phase 1 and Phase 2 child stories completed
