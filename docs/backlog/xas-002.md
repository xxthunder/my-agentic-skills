# [XAS-002] Rename repo and restructure as agentic-skills marketplace

**Status**: Open
**Priority**: High
**Component**: repo-wide

**Summary**:
As a maintainer, I want the repo renamed to `xxthunder-agentic-skills` and repositioned as an agent-agnostic skill marketplace so that it can host skills targeting multiple agents beyond Claude Code.

**Description**:
The repo is currently named `xxthunder-dev-skills` and framed as a Claude Code plugin. The new positioning: an "agentic skill marketplace" that hosts the dev skills as one plugin while being structured to support multiple agent targets. This epic covers the rename and supporting updates.

Child stories:
- XAS-005 — Rename repo and update references
- XAS-006 — Update plugin and marketplace manifests
- XAS-007 — Rewrite README to describe marketplace purpose

**Acceptance Criteria**:
- [ ] GitHub repo renamed to `xxthunder-agentic-skills`
- [ ] All internal references updated (plugin.json, marketplace.json, README, CLAUDE.md)
- [ ] Install instructions reflect the new name
- [ ] Child stories XAS-005 through XAS-007 completed
