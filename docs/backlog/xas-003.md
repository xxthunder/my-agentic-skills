# [XAS-003] Multi-agent skill authoring (single source, multi-target)

**Status**: Open
**Priority**: High
**Component**: skills/, build tooling

**Summary**:
As a skill author, I want to author each skill once in a canonical source format and generate per-agent artifacts so that skills stay DRY and new agent targets can be added without duplicating content.

**Description**:
Today, skills are authored in Claude Code's native plugin format. To support multiple agents (starting with Claude Code, later Copilot etc.), we need a canonical source format plus a generator that emits agent-specific artifacts. Initial scope: Claude Code target only, but the architecture must accommodate future targets.

**Substories**:
- XAS-003a — Define canonical skill source format
- XAS-003b — Build generator that emits Claude Code plugin artifacts
- XAS-003c — Document how to add a new agent target

**Acceptance Criteria**:
- [ ] Canonical source format defined and documented
- [ ] Generator produces valid Claude Code plugin from canonical source
- [ ] Generated artifacts pass existing plugin installation flow
- [ ] Adding a new agent target requires no changes to canonical sources
